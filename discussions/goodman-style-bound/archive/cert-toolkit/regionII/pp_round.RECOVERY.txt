Module docstring
----------------
Peyrl-Parrilo rational rounding for the joint (q, s-vars) Positivstellensatz SOS certs.

Replaces the naive "round-to-D then poke single entries to restore coefficient match"
rationalizer shared by gen_linear/gen_bivar/gen_trivar/gen_4var.  That scheme dumps the
whole rounding residual into individual Gram entries (destroying PSD near the SDP margin,
so it FAILS below RHO~12/25).  Here we instead:

  1. Solve the affine coefficient-matching system A vec(G)=c once, exactly, for a rational
     PARTICULAR solution vpart (small denominator, independent of D) plus an INTEGER null
     basis N of A (the Gram "ideal"/free directions).
  2. Round the SDP interior point into the affine subspace by choosing null coordinates z
     (G = vpart + N z) via Babai nearest-plane (round in the QR-orthogonalised null basis)
     at denominator D, so the result is EXACTLY feasible and stays at denominator ~D.
  3. Sweep D upward; accept the first denominator at which every block is PSD.

Because the correction is distributed over the full null space (not concentrated in one
entry) and orthogonalised, it stays inside the PSD cone using the whole SDP margin -- this
reaches the path-cert math frontier (RHO=97/200, p>=0.515) where the old scheme fails, and
where it overlaps the old scheme it produces SMALLER coefficients (lower LDL Hadamard
growth), which is what keeps the heavy Lean blocks within memory.

`rationalize(weights, svars, target, Gf, Dlist)` returns (D, [sympy Matrix per block]) or
None.  `weights[k] = (weight_poly_in_q, basis_k)`, each basis a list of exponent tuples
`(q_exp, s1_exp, ...)`; `target` a sympy poly in (q, *svars); `Gf` the float Grams.
